# Презентация «СинтексПруф» для акселератора ДГУ / TechNet

- **`СинтексПруф_TechNet_ДГУ_2026.pptx`** — версия для редактирования: новый текст, карточки и таблицы доступны как объекты PowerPoint. Иллюстрации и оформление исходного PDF-шаблона используются как фоны слайдов.
- **`СинтексПруф_TechNet_ДГУ_2026.pdf`** — версия для просмотра и отправки, 13 страниц.

## Основание и статус утверждений

Содержание построено на предоставленном «Акселератор.pdf» (6 страниц), предоставленном «Шаблон презентации 2.0_2026.pdf» (13 страниц) и [странице акселератора ДГУ TechNet](https://pt.2035.university/accelerator/747). Поддержка языков C/C++/Python дополнительно сверена с `README.md` этого репозитория. Скриншот демо на слайде 3 взят со страницы 3 исходного питча. Упоминание **20–30% времени на Code Review** — оценка исходного питча без приложенной методики измерения. Отличение кода человека от LLM-фрагментов в питче заявлено как цель: метрик точности нет, и это явно обозначено на слайде 3.

Для таблицы аналогов на слайде 5 дополнительно использованы открытые описания продуктов, без заявлений о превосходстве по точности или цене:

- [SonarQube: правила анализа](https://docs.sonarsource.com/sonarqube-server/quality-standards-administration/managing-rules/rules) и [AI CodeFix](https://docs.sonarsource.com/sonarqube-server/latest/user-guide/issues/fixing/);
- [CodeRabbit: обзор ревью](https://docs.coderabbit.ai/guides/code-review-overview);
- [GitHub Copilot: code review](https://docs.github.com/copilot/concepts/agents/coding-agent/about-coding-agent).

**Что ещё требуется для фактически полной заявки:** подтверждённый состав команды и опыт, результаты CustDev и оценки рынка, цена/экономика внедрения, письма партнёров и данные пилотов, верифицированный УГТ, не менее пяти независимых экспертных заключений с ФИО и ссылками. Эти сведения **не выдуманы**: соответствующие слайды различают подтверждённое, план и гипотезу.

## Повторная сборка

```bash
python -m venv .venv
.venv/bin/pip install pymupdf python-pptx pillow
.venv/bin/python presentations/build_deck.py \
  --template '/путь/к/Шаблон презентации 2.0_2026.pdf' \
  --source '/путь/к/Акселератор.pdf'
```

Для генерации PDF требуется доступный шрифт DejaVu Sans (`/usr/share/fonts/truetype/dejavu`). После сборки исходные PDF не нужны для просмотра или редактирования готовых файлов.
